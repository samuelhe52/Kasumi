licensed under MIT. The Rust package records its upstream reference as
dagre.js 3.0.1-pre, revision 4713b59bfa05af56cf58aa01e2027adf5d2dcf88.

The registry dependency is unmodified. Our C ABI and Swift wrapper are authored
application code.

Dagre 0.1.1 unconditionally compiles its graph/json module even with default
features disabled. The explicit serde feature is needed for compilation;
serde_json and the remaining default features are disabled.
