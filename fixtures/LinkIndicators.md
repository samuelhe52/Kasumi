# Link indicators

Ordinary text stays unmarked. Heading and web links have a muted solid line below the baseline; file and other links have a muted dashed line.

- [A longer link that wraps across lines should remain underlined on each line, including the words at both ends](#destination)

- [**Bold**, *italic*, and plain link text](#destination).

- [`linked code`](#destination) beside ordinary `code`.
- [Text beside $x_i$ inside a link](#destination).
- [A relative file link](LinkJumps.md) and [an email link](mailto:reader@example.com) use dashes.
- [Repeated p stems: repeated pepper paper](#destination).
- [Curved g loops: heading singing gathering](#destination).
