# 标点,排版 (示例)

Les mots de cette page sont pour les lecteurs avec une langue dans le document. Nous vous montrons ce texte et ses possibilités de composition, sans modifier les caractères du texte original.

汉,字.句;子:好!吗? 汉(API)字. 数字 3.14、1,000、12:30 保持原样.

中文和 English, words 共同排版. 汉, abc 和 abc,def 使用局部上下文. 连续标点!!!和括号(内容)也参与排版.

**粗体,标点**与*斜体,标点*保持样式. `代码,标点`、$x,y$ 和 [链接,标签](https://example.com/a?x=1) 保持原样.[^note]

日本語,です. カナがある段落は変換しません!

한글,문장. 이 문장은 바꾸지 않습니다!
